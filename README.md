A high-performance, accessible, and modern landing page for a digital agency. Built with a focus on speed, SEO, and developer experience.

🔗 **Live Demo:** [https://aura-boogie-demo-v1.netlify.app](https://aura-boogie-demo-v1.netlify.app)

## 🚀 Features

*   **Responsive Design:** Mobile-first approach using Tailwind CSS.
*   **Internationalization (i18n):** Full English/Hebrew support with RTL/LTR switching via Alpine.js.
*   **Animations:** Smooth scroll animations powered by AOS.
*   **Forms:** Integrated Netlify Forms for serverless submission handling.
*   **Accessibility (a11y):** WCAG AA compliant (Skip links, ARIA labels, semantic HTML).
*   **PWA Ready:** Includes manifest and meta tags for installation.

## 🛠️ Tech Stack

*   **Framework:** Alpine.js (Lightweight reactivity)
*   **Styling:** Tailwind CSS (Utility-first)
*   **Deployment:** Netlify (CI/CD connected to GitHub)
*   **Icons:** Heroicons (SVG)

## 📂 Project Structure

```bash
aura-website/
├── assets/
│   └── img/          # Optimized images
├── index.html        # Main entry point (Single File Component style)
├── manifest.json     # PWA configuration
├── robots.txt        # SEO directives
└── sitemap.xml       # Search engine map
```

## 🔧 Setup & Development

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/chagaidev/aura-website.git
    ```

2.  **Open `index.html`:**
    No build step required for local development! Just open the file in your browser.

3.  **Deploy:**
    Push to `main` branch to trigger automatic deployment via Netlify.
